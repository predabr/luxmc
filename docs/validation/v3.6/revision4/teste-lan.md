# Teste da sala entre os dois PCs

Usem o mesmo arquivo **Lux MC Launcher.exe**, versão 3.6.0, revisão 4. A revisão aparece na interface de Jogar juntos. Instalar a atualização conserva os mundos e as instâncias.

1. Nos dois computadores, abram o Luxmc e usem a mesma versão do Minecraft Java e o mesmo modpack, quando houver mods.
2. Um de vocês abre **Amigos → Jogar juntos → Criar minha sala** e escolhe **Copiar convite**.
3. O outro abre **Entrar na sala**, cola o convite e entra. Confiram se os dois participantes aparecem.
4. Quem vai hospedar entra em um mundo do Minecraft e escolhe **Abrir para LAN**.
5. Confiram se o mundo aparece em **Mundos da turma** no Luxmc. No outro Minecraft, abram **Multijogador** e aguardem a entrada em **Jogos na rede local**.
6. Entrem pela entrada LAN, permaneçam alguns minutos e testem movimento, blocos e troca de abas no Luxmc. Mantenham o launcher aberto em segundo plano.

Se falhar, registrem em qual etapa aconteceu, a mensagem exata e se a sala mostrou o mundo. Não compartilhem o convite privado em prints públicos. Permissões do Java no firewall, a conexão com o relay e a compatibilidade dos mods ainda podem influenciar o resultado.

Os testes automatizados aprovaram o relay público, a resolução do convite e a descoberta por um listener padrão do Java 8. Este roteiro valida a partida real entre os dois computadores; ela ainda não foi realizada nesta revisão.
