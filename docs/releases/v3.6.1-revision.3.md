# Luxmc 3.6 — Jogar Juntos, revisão 3

As salas de Minecraft Java passam a usar túneis QUIC integrados com conexão direta ou relay criptografado. O Luxmc anuncia os mundos nas interfaces locais para que apareçam na lista LAN do Minecraft. O fluxo não instala EasyTier nem drivers de VPN.

- Sala com perfis, avatares, mundos disponíveis, convite simples, controle de entradas e renovação do convite de 24 horas. É possível navegar por Amigos e outras abas mantendo a conexão.
- Correção dos fundos quadrados em abas de configurações e instâncias quando há wallpaper personalizado.
- Painel exclusivo da conta autenticada do dono com perfis online, jogadores ativos, busca e tags públicas como Testador, Amigo e Plus. As tags não concedem acesso administrativo.
- Cancelamento identificado por instalação em todas as etapas da fila. O estado é preservado entre download e importação; um cancelamento antigo não afeta a próxima instalação. O registro só é confirmado após a conferência final, e resultados atrasados são descartados.
- Conferência de arquivos com até quatro tarefas paralelas e interrupção durante extração e cálculo de hashes. A duração depende do pacote, armazenamento e antivírus.
- Correção do avatar de reserva quando a primeira imagem não está disponível.
- Shield com leitura por blocos, cache associado ao conteúdo, detecção corrigida de webhooks e bloqueio quando um JAR crítico ou uma falha impede a verificação. Sinais isolados geram avisos, sem apagar mods automaticamente. A oficina oferece a verificação manual dos mods.
- A detecção de Java confere se o executável realmente funciona e inclui Java 16 e 25 no gerenciamento e reparo. A remoção de runtimes é bloqueada durante uma partida. As pastas do sistema no Windows são protegidas também quando o caminho usa maiúsculas e minúsculas diferentes.
- Atualização de dependências com correções de segurança publicadas.

Frontend, backend, acesso exclusivo do dono, cancelamento, transporte via relay público, serviço real de convites e descoberta com listener Java foram testados. O teste de partida no Minecraft entre dois computadores em redes diferentes ainda precisa ser realizado. Este modo de sala atende ao Minecraft Java; não representa uma VPN para todos os aplicativos do PC.

Instalador: **Lux MC Launcher.exe**. A atualização preserva contas, instâncias, mundos e preferências.
