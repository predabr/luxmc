Luxmc 3.0.1 corrige a restauração de wallpapers animados, melhora as salas P2P e adiciona o compartilhamento de aparência entre contas Luxmc. O nome do instalador continua **Lux MC Launcher.exe**.

- Wallpapers animados são restaurados das configurações salvas e usam a porta atual do servidor de vídeo após reabrir o launcher.
- Cartões da biblioteca inicial ficaram mais compactos; o perfil do jogador mostra conta, tempo jogado e instâncias com ações organizadas.
- Uma sala pode ser criada antes de abrir o Minecraft. Ao abrir o mundo para LAN, o Luxmc detecta a porta automaticamente e acompanha a troca de mundo sem pedir outra porta ou convite.
- O convidado vê quando o mundo ainda não está aberto para LAN; a descoberta no Minecraft começa quando o mundo fica disponível.
- Contas Luxmc publicam skin e capa ao aplicar. Outros clientes compatíveis podem buscar essa aparência pelo perfil do jogador. Contas Microsoft continuam usando as skins oficiais; contas locais mantêm personalização local. Um pacote de recursos sozinho não implementa skins individuais de outros jogadores.
- A preparação reutiliza o agente de aparência quando o arquivo não mudou. Sessões antigas do Minecraft são ocultadas dos registros coletados pelo launcher.
- Forge e NeoForge usam caminhos consistentes entre os módulos do Java e as bibliotecas do jogo, corrigindo o carregamento duplicado em diretórios redirecionados do Windows. Erros anteriores à criação do log do Minecraft também aparecem no diagnóstico.
- O banco local usa acesso serializado e cria uma cópia diária verificada antes das migrações. Dados corrompidos geram um erro explícito e são preservados para recuperação.

Para multiplayer, os jogadores precisam usar versões e mods compatíveis e abrir o mundo para LAN. O túnel criptografado foi verificado com transferência real de dados, troca de portas e relay; o resultado entre computadores também depende da rede e das configurações do jogo.

A instalação preserva os dados do jogador. O instalador ainda não tem uma assinatura de editor reconhecida pelo Windows; renomear o arquivo não elimina avisos do SmartScreen.
