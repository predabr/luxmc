Luxmc 3.0 reúne a atualização do launcher, do portal e do instalador, mantendo o nome Lux MC Launcher.

- Interface revisada, cartões de instâncias maiores, ícones de modpacks e contraste corrigido no tema claro.
- Wallpapers importados ficam na biblioteca do launcher, com prévia e opções de transparência.
- Catálogo de mods, modpacks, resource packs, shaders, data packs e mundos com seleção de instâncias compatíveis.
- Personalizador com catálogo NameMC, skin e capa por visual salvo, aplicação e sincronização com Microsoft.
- Correções nas salas de multiplayer, nos convites curtos e nas solicitações de amizade.
- Reutilização de arquivos e caches na preparação do Minecraft, gestão de Java e opções de desempenho por instância.
- Idioma automático do sistema, com português, inglês e espanhol; outros idiomas usam inglês.
- Notícias oficiais do Minecraft atualizadas automaticamente, com cache e recuperação após reconexão.
- Atualizador revisado e desinstalador Windows com verificação da remoção do executável e preservação dos dados do jogador.
- Portal atualizado com downloads ligados aos arquivos deste lançamento.

No Windows, baixe **Lux MC Launcher.exe**. A atualização preserva contas, skins, instâncias e mundos. Por padrão, o desinstalador remove o aplicativo e mantém os dados para uma instalação futura; deixe desmarcada a opção de excluir dados.

Contas Microsoft publicam a skin no perfil oficial do Minecraft. Skins de contas Luxmc dependem dos recursos de aparência do launcher; capas importadas são locais. Para multiplayer com mods, use versões e modpacks compatíveis nos dois computadores e abra o mundo para LAN.

Os instaladores disponíveis aparecem nos arquivos abaixo. `SHA256SUMS` contém as somas de verificação; `latest.json` fornece os endereços para o atualizador. Uma assinatura de código reconhecida pelo Windows ainda é necessária para identificar o editor: o nome do arquivo não garante ausência de avisos do SmartScreen.
